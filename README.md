# ShipBoard Pro 🚢

لوحة متابعة الشحنات والفواتير — مبنية بـ HTML/JS خالص، تقرأ البيانات مباشرة من Google Sheets.

## الميزات
- ثنائي اللغة (عربي / إنجليزي) مع دعم RTL
- وضع داكن / فاتح
- تحديث تلقائي كل 5 دقائق من Google Sheets
- KPIs + رسوم بيانية تفاعلية
- جدول بحث وفلترة وتصدير Excel
- تنبيهات ذكية للشحنات المتأخرة والقادمة
- ملخص تنفيذي تلقائي

## مصدر البيانات
Google Sheets منشور كـ CSV — يُحدَّث تلقائياً كل 5 دقائق.

## النشر
يتم النشر تلقائياً على GitHub Pages عند كل push عبر GitHub Actions.
